# Microplastics in Remote Streams

A field-study site for a BYU–Idaho Chem 490R internship project tracking
microplastic contamination in headwater streams around Kilgore, Idaho (Clark
County) and Rexburg, Idaho (Madison County).

Built with React, Tailwind CSS v4, Framer Motion, Leaflet, and Recharts.

## Team

Ryan Sargeant, Lydia Kessie, Cheyenne Gwynn, Kiersten Jensen

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` deploy automatically to GitHub Pages via
`.github/workflows/deploy.yml`. On a brand-new repo, enable
**Settings → Pages → Source → GitHub Actions** once, then re-run the workflow.
